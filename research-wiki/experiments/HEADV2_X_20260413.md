# HEADV2_X_20260413

## 目的
验证 IrregularActionFormerHeadV2 (soft assign + asymmetric log1p reg + final k=1) 在 dense proj/neck 下的性能。
这是 X/Y 隔离对照的 X 线：dense projection + dense neck + HeadV2。

## 配置
- Projection: GridAwareConv1DTransformerProj (dense-like, 传递 temporal_grid)
- Neck: GridAwareFPNIdentity (dense-like, 传递 temporal_grid)
- Head: IrregularActionFormerHeadV2
  - soft_assign_topk=9, cost-based top-k per GT
  - asymmetric log1p regression: log1p(left/cell_left), log1p(right/cell_right)
  - branch convs k=3, final predictor k=1
- 输入: random-fixed 50% (fresh features)

## 结果

| Epoch | Avg-mAP | mAP@0.7 |
|-------|---------|---------|
| 39 | 46.09 | 18.74 |
| 44 | 47.75 | 21.13 |
| 49 | 49.07 | 22.47 |
| 54 | 50.22 | 24.11 |
| **59** | **51.04** | **25.04** |

## 对照

| 实验 | Avg-mAP | Delta vs X |
|------|---------|-----------|
| dense baseline (random-fixed) | 63.12 | -12.08 |
| **headv2_x** | **51.04** | 0 |
| headv2_y (final) | 49.00 | -2.04 |
| 旧 irregular_actionformer | 39.04 | -12.00 |
| native irregular remap_no_regrange | 4.13 | -46.91 |

## 结论

1. HeadV2 成功把 irregular detector 从"语义崩溃"拉回到"稳定可学"状态。
2. 曲线持续上升，无抖动，说明 soft assignment + asymmetric reg 的 supervision 语义是自洽的。
3. 仍差 dense baseline 12.08 mAP，残差来源待 ablation 确认：
   - final k=1 是否过于激进？→ ablation_k3
   - soft_assign_topk=9 是否弱于 hard assignment？→ ablation_topk1
4. X > Y 初步说明 dense proj/neck 优于 irregular proj/neck（Y 最终结果待确认）。
