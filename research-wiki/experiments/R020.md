# R020: Hard + REINFORCE Policy Gradient

## 目的
用 RL policy gradient 桥接 hard masking 的梯度断裂，det loss 作 reward。

## 结果
| Metric | Value |
|--------|-------|
| Avg-mAP | 53.96% |
| mAP@0.5 | 56.81% |
| mAP@0.7 | 28.51% |

## 失败分析
- REINFORCE reward 信号方差大，策略未收敛
- 与 R021 (soft gating, 53.98%) 几乎一致，说明两种梯度方案都无法有效训练 scorer
