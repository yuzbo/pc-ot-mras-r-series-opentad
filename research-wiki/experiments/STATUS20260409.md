# Current TAD Experiment Status Snapshot (2026-04-09)

## Purpose
用一页总结当前智能选帧 TAD 项目的真实进展，避免实验线过多后结论碎片化。

## Current Best Verified Result
- **R008 / v3_uniform_50pct_p0fix.py**
- Avg-mAP = **63.74%**
- 结论：目前最稳、最可信的 50% 路线仍然是 uniform，而不是 learned scorer。

## Learned Sampler Status
- **R017** hard + BCE + coarse_det = 57.55%
- **R018** hard + coarse_det only = 47.68%
- **R021** gumbel soft-gating minimal = 53.98%

结论：到 2026-04-09 为止，learned sampler 还没有超过 uniform 50%，且 scorer 学习质量不足仍是主问题。

## Structural Findings
1. 稀疏/压缩时间轴不能直接复用 dense ActionFormer 假设。
2. compressed / sparse / bridge 线暴露出 projection、adapter、classification 的不稳定链路。
3. 当前最值得继续验证的是：
   - oracle 50% 上界
   - projection-aware 优化（indicator / bias / inject）
   - coarse inject / hard-friendly scorer training

## Conclusion
项目尚未证明“智能选帧优于均匀选帧”，但已经证明：
- 50% uniform 在该框架下可行；
- naive learned scorer 设计不够；
- sparse-aware detector/projection 是后续关键。
