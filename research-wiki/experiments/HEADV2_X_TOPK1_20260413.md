## Interpretation

1. `topk=1` is clearly worse than the default soft assignment (`47.19` vs `51.04`, `-3.85`).
2. So soft multi-point assignment is helping, not hurting.
3. This means the residual gap of `HeadV2-X` should not be blamed mainly on "assignment being too soft".
4. The next higher-probability residual sources remain:
   - final predictor `k=1` vs `k=3`
   - projection / neck / backbone time-geometry mismatch
   - broader irregular-detector structure beyond assignment alone
